  Hydro Reminder
</h1>

<p align="center">
  O <strong>Hydro Reminder</strong> ajuda você a se manter hidratado enviando lembretes amigáveis na área de trabalho para beber água em intervalos regulares.
</p>

## <img src="https://github.com/KrishBharadwaj5678/HydroReminder/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| -------- | --------- |
| 💧 Lembretes para Beber Água | Envia notificações para lembrar você de beber água |
| ⏰ Alertas Programados | Permite configurar intervalos personalizados para os lembretes |
| 🔔 Notificações na Área de Trabalho | Sistema leve de notificações para desktop |
| ⚡ Fácil de Usar | Interface simples e intuitiva |
| 🌐 Interface com Streamlit | Experiência interativa baseada na web |

## <img src="https://github.com/KrishBharadwaj5678/HydroReminder/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/HydroReminder.git
```

### 2️⃣ Acesse a Pasta do Projeto

```bash
cd HydroReminder
```

### 3️⃣ Instale as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute a Aplicação

```bash
streamlit run app.py
```
