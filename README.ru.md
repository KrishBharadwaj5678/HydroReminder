<h1 align="center">
  <img src="https://github.com/KrishBharadwaj5678/HydroReminder/raw/main/water.ico" width="35"/>
  Hydro Reminder
</h1>

<p align="center">
  <strong>Hydro Reminder</strong> помогает поддерживать водный баланс организма, отправляя дружелюбные напоминания на рабочий стол о необходимости выпить воды через заданные промежутки времени.
</p>

## <img src="https://github.com/KrishBharadwaj5678/HydroReminder/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ------------ | -------- |
| 💧 Напоминания о воде | Отправляет уведомления с напоминанием выпить воды |
| ⏰ Настраиваемые интервалы | Позволяет установить собственный интервал между напоминаниями |
| 🔔 Уведомления на рабочем столе | Лёгкая и быстрая система уведомлений |
| ⚡ Простота использования | Чистый и понятный интерфейс |
| 🌐 Интерфейс Streamlit | Интерактивный веб-интерфейс |

## <img src="https://github.com/KrishBharadwaj5678/HydroReminder/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/HydroReminder.git
```

### 2️⃣ Перейдите в папку проекта

```bash
cd HydroReminder
```

### 3️⃣ Установите зависимости

```bash
pip install -r requirements.txt
```

### 4️⃣ Запустите приложение

```bash
streamlit run app.py
```
