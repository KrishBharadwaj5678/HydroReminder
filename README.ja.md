<h1 align="center">
  <img src="https://github.com/KrishBharadwaj5678/HydroReminder/raw/main/water.ico" width="35"/>
  Hydro Reminder
</h1>

<p align="center">
  <strong>Hydro Reminder</strong> は、一定間隔で水分補給を促すデスクトップ通知を送信し、健康的な水分習慣をサポートするアプリケーションです。
</p>

## <img src="https://github.com/KrishBharadwaj5678/HydroReminder/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| 💧 水分補給リマインダー | 水を飲むように通知を送信します |
| ⏰ 時間指定アラート | リマインダー間隔を自由に設定できます |
| 🔔 デスクトップ通知 | 軽量な通知システムを提供します |
| ⚡ 使いやすさ | シンプルで直感的なインターフェース |
| 🌐 Streamlit UI | インタラクティブなWebベースの操作画面 |

## <img src="https://github.com/KrishBharadwaj5678/HydroReminder/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/HydroReminder.git
```

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd HydroReminder
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリを起動

```bash
streamlit run app.py
```
